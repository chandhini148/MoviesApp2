# CineScope 🎬

**Discover • Explore • Enjoy**

CineScope is an Android movie discovery application that allows users to explore movies, discover trending titles, view movie details and manage their accounts.

## Features

- User Registration and Login
- Firebase Authentication
- Forgot Password functionality
- Movie discovery using TMDB API
- Movie details and browsing
- Jetpack Compose user interface
- Dark-themed UI
- Cloud Firestore integration

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3
- Firebase Authentication
- Cloud Firestore
- TMDB API
- Retrofit
- Coil

## Architecture

MVVM (Model-View-ViewModel)

## Setup Instructions

1. Clone this repository.
2. Open the project in Android Studio.
3. Add your own `local.properties` file with your TMDB API key.
4. Add your Firebase `google-services.json` file inside the app directory.
5. Sync Gradle.
6. Build and run the application.

## API Configuration

Get your TMDB API key from https://www.themoviedb.org/.

Configure the key in `local.properties`:

TMDB_API_KEY=your_api_key

Firebase configuration must also be added before running the application.
